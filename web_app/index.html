Macro F0.5 Metric Nuance & Singleton Reward

In the official challenge specification, evaluation uses Macro $F_{0.5}$: $$F_{0.5} = \frac{1.25 \times \text{Precision} \times \text{Recall}}{0.25 \times \text{Precision} + \text{Recall}}$$ A false merge cuts precision and is penalized 2× more severely than a false negative. Furthermore, true singletons (entities with 0 true matches) receive a full score of 1.0 if predicted empty, and 0.0 if falsely linked. Our system uses a high-precision threshold (τ = 0.375) preventing spurious merges.

Strict Open-Set Country Guarantees

The test set contains open-set countries such as France alongside US and India. Our blocking engine enforces a hard country constraint: entities from Source 1 are only ever paired with candidates from the exact same normalized country. This mathematically guarantees 0 cross-country candidate errors across all test queries.
